IDS Inference API Format Sample

Endpoint: POST /predict
Content-Type: application/json

1. Request Payload (Input)
--------------------------
{
  "features": {
    "Fwd Header Len": 128,
    "Protocol": 6,
    "Init Bwd Win Byts": 64,
    "Tot Fwd Pkts": 4,
    "Pkt Len Max": 30,
    "Pkt Len Mean": 7.1,
    "Tot Bwd Pkts": 5,
    "Dst Port": 4444,
    "Bwd Pkt Len Max": 23,
    "Fwd Pkts/s": 14.83,
    "Flow IAT Max": 257068.0,
    "TotLen Bwd Pkts": 23.0,
    "TotLen Fwd Pkts": 48.0,
    "Bwd Pkt Len Std": 10.28,
    "Bwd Pkt Len Mean": 4.6,
  },
  "scaler_id": "default"
}

2. Response Payload (Output)
----------------------------
{
  "isolation_forest": {
    "flag": 1,
    "confidence": 0.5,
    "delay": "0.1ms"
  },
  "xgb": {
    "flag": 1,
    "confidence": 0.854,
    "delay": "0.1ms"
  },
  "gnn": {
    "flag": "U2R",
    "confidence": 0.1,
    "delay": "0.1ms"
  },
  "verdict": "ZERO_DAY_SUSPICION",
  "action": "block"
}

Field Descriptions:
- isolation_forest:
  - flag: 1 for anomaly, 0 for normal
  - confidence: Anomaly score
  - delay: time taken for isolation forest model to return the result
- xgb:
  - flag: 1 if attack, 0 if normal
  - confidence: Probability score of the prediction
  - delay: time taken for xgb model to return the result
- gnn:
  - flag: Specific attack class (e.g., U2R, DoS, Probe)
  - confidence: Probability score of the classification
  - delay: time taken for gnn model to return the result
- verdict: Final aggregated decision (BENIGN, KNOWN_ATTACK, ZERO_DAY_SUSPICION)
- action: Recommended mitigation action

Example Mitigation Actions:
- "block": Immediately drop packets from source IP.
- "monitor": Log traffic but allow flow to continue.
- "alert": Send notification to dashboard/admin but take no automated network action.
- "quarantine": Move host/flow to a restricted VLAN.
