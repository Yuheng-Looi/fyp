IDS Inference API Format Sample

Endpoint: POST /predict
Content-Type: application/json

1. Request Payload (Input)
--------------------------
{
  "features": {
    "Fwd Header Len": 128,
    "Protocol": 6,
    "Init Bwd Win Byts": 64,
    "Tot Fwd Pkts": 4,
    "Pkt Len Max": 30,
    "Pkt Len Mean": 7.1,
    "Tot Bwd Pkts": 5,
    "Dst Port": 4444,
    "Bwd Pkt Len Max": 23,
    "Fwd Pkts/s": 14.83,
    "Flow IAT Max": 257068.0,
    "TotLen Bwd Pkts": 23.0,
    "TotLen Fwd Pkts": 48.0,
    "Bwd Pkt Len Std": 10.28,
    "Bwd Pkt Len Mean": 4.6,
    "src": "192.168.1.105",
    "dst": "10.0.0.5"
  },
  "scaler_id": "default"
}

2. Response Payload (Output)
----------------------------
{
  "verdict": "KNOWN_ATTACK",
  "confidence": 0.998,
  "source": "192.168.1.105",
  "destination": "10.0.0.5",
  "scaler_used": "default",
  "gnn_verdict": "U2R",
  "details": {
    "safety_net_flag": 1,
    "xgb_flag": 1,
    "xgb_probability": 0.998,
    "gnn_multiclass": "U2R",
    "gnn_confidence": 0.854
  }
}

Field Descriptions:
- verdict: Final decision (BENIGN, KNOWN_ATTACK, ZERO_DAY_SUSPICION)
- confidence: Confidence score of the primary detector (XGBoost)
- gnn_verdict: The specific attack class predicted by the GNN (e.g., DoS, DDoS, PortScan, Normal)
- details:
  - safety_net_flag: 1 if anomaly detected by Isolation Forest, 0 otherwise
  - xgb_flag: 1 if attack detected by XGBoost, 0 otherwise
  - gnn_multiclass: Same as gnn_verdict
  - gnn_confidence: Confidence score of the GNN prediction
