Legend
SCS (Service Continuity Score): calculated from empirical HTTP/QoS tick state history (ACTIVE=1.0, DEGRADED=0.5, DOWN=0.0). Evaluates service availability during attack ticks.
QPS (QoS Preservation Score): calculated from 0.50 * QPS_Throughput + 0.50 * QPS_Latency. Measures benign throughput retention and baseline latency preservation.
UIS (User Impact Score): calculated from continuous duration-weighted user experience impact during attack windows (0.50 * Throughput_Ratio + 0.50 * Latency_Ratio).
RES (Recovery Effectiveness Score): calculated from controller mitigation activation delay (Sub-100ms response = 1.0, Unmitigated/SS13 = 0.0).
NRS (Network Resilience Score): combined network operational resilience score calculated from (0.30 * SCS) + (0.25 * QPS) + (0.25 * UIS) + (0.20 * RES).
WS (Web Server Survival): calculated from Web Server asset protection against web payload delivery (Protected=1.0, Compromised/Unmitigated=0.0).
DB (Database Preservation Score): calculated from Database Server asset protection against database injection/exfiltration payload delivery (Protected=1.0, Compromised/Unmitigated=0.0).
SPS (Security Preservation Score): security score calculated from 0.50 * WS + 0.50 * DB.
Overall (OFS / Overall Framework Score): top-level composite evaluation score calculated from 0.50 * NRS + 0.50 * SPS.
